# Retail Sales Dashboard

## Project Overview
This project analyzes retail sales data using Excel and Power BI.

## Key Insights
- Total Sales
- Total Profit
- Average Sales
- Repeated Customers
- Profit Margin
- Discount Analysis

## Tools Used
- Microsoft Excel
- Power BI
- DAX

## Dashboard  
An interactive Power BI dashboard was created to analyze sales performance, profitability, customer behavior, and discounts.
